Datos de conexión

Se graban en la placa por USB desde tu navegador. No se envían a ningún servidor ni se guardan en esta página.

La pantalla

Así la verás en la lista de dispositivos de tu router. Déjalo como está o pon el que quieras: solo letras, números y guiones.

La API el programa que reúne los datos y se los pasa a la pantalla

La IP del equipo donde instalarás la API (paso 4) y el puerto. Elige el que prefieras: la API quedará escuchando justo ahí. Lo habitual es :8787; sin puerto se usa el 80.

No sé cuál es la IP de mi equipo

Entra en ese equipo y ejecuta hostname -I: el primer número que salga es su IP. También puedes usar su nombre seguido de .local, por ejemplo http://raspberrypi.local:8787; el nombre lo da el comando hostname.

Solo para direcciones https://. La pantalla comprobará que el certificado es este antes de enviar el token. Si lo dejas vacío la conexión va cifrada, pero cualquiera que se haga pasar por tu servidor podría recibir el token.

Es la contraseña entre la pantalla y la API. Ya te he generado uno; el mismo valor aparece en los comandos del paso 4.
